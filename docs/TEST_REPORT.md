## 开发过程中发现并修复的问题

1. `src/main.rs` 缺失导致 bin 目标不存在（首次打包无 exe）→ 补建入口。
2. `AppState` 双层锁（Mutex<Database> 内含 Mutex<Connection>）导致 40+ 类型错误 → 简化为 `Arc<Mutex<Connection>>` 单层锁。
3. `PoisonError<MutexGuard>` 经 `?` 转 `Box<dyn Error>` 会把局部引用提前返回（E0515）→ 锁错误统一 map 成无守卫消息。
4. `pick_files/pick_file/shortcut_status` 未注册进 invoke_handler → 补注册（否则前端调用运行时失败）。
5. 前端 `mode-changed` 事件载荷为对象 `{compact}`，前端按布尔解析导致迷你→正常视图不切换 → 修正解析。
6. crates.io 直连超时 → 配置 rsproxy 镜像。
7. `rusqlite` backup 需显式 feature；`StepResult` 枚举处理 Busy/Locked 重试。

## 安全用例

- Markdown 原始 HTML / 事件属性 / `javascript:`、`file:` 链接注入 → 全部转义或拒绝（Vitest 用例）
- 附件路径穿越 → Rust canonicalize + starts_with 校验（services/resources.rs）
- SQL 注入 → 全参数化，前端无 SQL 通道
- 链接打开仅 http(s)；图片内联协议仅 image 类 + 64MB 上限 + UUID 校验
