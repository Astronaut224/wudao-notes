# 吾道笔记 · 操作说明

## 安装与首次启动

1. 双击 `吾道笔记_1.0.0_x64-setup.exe`（NSIS 安装包，位于发布产物目录）。
2. 按提示完成安装（仅当前用户，不需要管理员）；首次启动界面为空数据。
3. 卸载不会删除本地数据（位于 `%LOCALAPPDATA%\cn.wudao.notes\`）；如需彻底清理请手动删除该目录。

> 绿色运行：也可直接运行 `吾道笔记.exe`（免安装版，数据位置相同）。

## 界面总览

- 左侧导航只有两项：**待办**、**笔记**；左下角 ⚙ 为设置。
- 待办页：中栏清单（分组/筛选/新建），右侧为选中条目的详情（就地编辑）。
- 笔记页：中栏笔记列表，右侧 Markdown 编辑器（可切换预览）。

## 日常操作

### 待办
- **新建**：`＋ 新建待办`（或 `Ctrl+N`）→ 输标题、选优先级（默认中）→ 保存，三步完成。
- **排序**：拖动条目到组内新位置；拖到其他分组会同时修改优先级。右键菜单提供上移/下移（键盘可达）。
- **完成/恢复**：点击左侧方框一键完成；在「已完成」筛选中可再次点击恢复为未完成。
- **详情**：点击条目，右侧直接编辑标题、优先级、截止日期、下一步、备注；停止输入约 0.6 秒自动保存。
- **添加资料**：详情页「相关资料」区 → `＋ 文件/图片` 或 `＋ 添加链接`，也可直接把文件拖进来。默认**复制进应用**（原文件移动/删除不影响）；勾选「仅引用原始文件位置」则不复制，原文件移动后会提示失效并可一键重新定位。
- **关联笔记**：详情页「关联笔记」→ `＋ 新建笔记` 自动关联；删除待办时笔记保留、仅解除关联。

### 笔记
- **新建**：`＋ 新建笔记`（或 `Ctrl+N`）。
- **编辑**：右侧输入 Markdown；工具栏可插入粗体/标题/列表/代码块/链接；`▦ 预览` 查看渲染效果。
- **分类**：输入单层分类（如 SQL、会议纪要），列表顶部按分类筛选。
- **置顶/归档/删除**：编辑器右上角按钮。
- **关联待办**：编辑器底部下拉选择（一个笔记最多关联一条待办）。

### 迷你悬浮窗
- 标题栏 `▣` 或托盘菜单「切换迷你模式」进入；窗口缩小为 340×440。
- 仅保留：查看最靠前的未完成待办、勾选完成、底部快速新增待办/快速记笔记、`□` 展开完整窗口。
- `☆` 切换置顶（状态记忆）；按住标题栏可拖动。

### 托盘与快捷键
- `Ctrl+Shift+Space`：呼出/隐藏窗口（可在设置中改键；被占用时会提示，仍可用托盘呼出）。
- `Ctrl+K`：聚焦搜索框；`Esc`：关闭弹窗。
- 点击 `×` = 隐藏到托盘，程序继续运行；彻底退出请用托盘右键菜单 → **退出**。
- 托盘菜单：打开吾道笔记 / 切换迷你模式 / 新建待办 / 退出。
- 再次双击桌面图标会激活已有窗口，不会启动第二个实例。

## 设置

左下角 ⚙：
- **全局快捷键**：修改呼出快捷键。
- **登录系统后启动**：默认关闭；开启后随系统启动并隐藏在托盘。
- **迷你窗置顶**：默认记忆开关。
- **备份**：导出 zip（数据库快照 + 托管附件）到任意位置。
- **恢复**：选择备份 → 自动校验 → 确认「覆盖当前全部数据」后执行。恢复后自动刷新界面。

## 数据安全说明

- 全部数据保存在本机，不联网上传。
- 复制模式附件的删除只影响应用内副本，不动原文件；「仅引用」模式应用永远不会删除你的原文件。
- 建议定期「导出备份」，重要操作（恢复）有二次确认。

## 常见问题

| 现象 | 处理 |
|---|---|
| 快捷键无效 | 可能被其他软件占用：设置中换一组键，或用托盘打开 |
| 附件显示「文件不存在」 | 该资料为「仅引用」模式且原文件已移动：点 ⟳ 重新定位；或将模式改为复制重新添加 |
| 双击图标没反应 | 应用已在运行（托盘中有图标），双击会唤起已有窗口 |
| 界面文字大小异常 | 缩放比例过高时窗口尺寸会随系统缩放，拖动窗口边缘可调整 |
